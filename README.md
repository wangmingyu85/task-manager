# 智能任务管理系统

Node.js（Express）+ Supabase（PostgreSQL）+ 原生静态前端。支持任务添加、完成状态切换、删除、按优先级筛选，任务按创建时间倒序，已完成任务自动加删除线。

## 目录结构

```
task-manager/
├── server.js            # Express 后端入口 + API
├── api/index.js         # Vercel Serverless 函数入口
├── public/              # 前端静态页面
│   ├── index.html
│   ├── style.css
│   └── app.js
├── vercel.json
├── .env.example
└── package.json
```

## 一、Supabase 建表（SQL Editor 执行一次）

```sql
create table if not exists tasks (
  id bigint generated by default as identity primary key,
  title text not null,
  priority text not null default '中' check (priority in ('高', '中', '低')),
  completed boolean not null default false,
  created_at timestamptz not null default now()
);

alter table tasks enable row level security;

create policy "Allow anon read"   on tasks for select using (true);
create policy "Allow anon insert"  on tasks for insert with check (true);
create policy "Allow anon update"  on tasks for update using (true) with check (true);
create policy "Allow anon delete"  on tasks for delete using (true);
```

> 教学演示用开放策略；正式项目应改为「登录用户只能操作自己的数据」。

## 二、本地运行

```bash
npm install
npm start
```

访问 http://localhost:3000

## 三、环境变量

`.env`（已被 `.gitignore` 忽略，不要提交到 GitHub）：

```
SUPABASE_URL=https://你的项目ID.supabase.co
SUPABASE_ANON_KEY=sb_publishable_你的key
NODE_ENV=production
CLIENT_BASE_PATH=/
```

## 四、API 一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/tasks?priority=高` | 列表（倒序，可选优先级筛选） |
| POST | `/api/tasks` | 添加任务 `{title, priority}` |
| PATCH | `/api/tasks/:id` | 切换完成状态 `{completed}` |
| DELETE | `/api/tasks/:id` | 删除任务 |

## 五、部署到 Vercel

1. 把代码推到 GitHub 公开仓库 `task-manager`。
2. Vercel → Add New → Project → Import 该仓库。
3. Environment Variables 逐条填入上面四个变量（变量名不要改）。
4. Deploy，等待 1～3 分钟，得到 `https://xxx.vercel.app`。
5. 可选：Domains 绑定自己的域名，按 Vercel 提示添加 CNAME 与 TXT 记录。
